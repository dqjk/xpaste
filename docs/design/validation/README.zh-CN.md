# UI 实现验收

验收环境：

- 地址：`http://192.168.2.199:3002`
- 浏览器：Chrome
- 桌面端：`1440 × 1100`
- 平板端：`834 × 1112`
- 移动端：`390 × 844`

## Figma 节点对比

文本卡片以 Figma 节点 `3:249` 为基准：

- Figma 卡片：`372 × 248`，左右内边距均为 `24px`。
- Figma Copy 按钮：`324 × 48`，占满内容区域。
- 桌面实现：卡片宽 `423px`，三列自适应，Copy 占满卡片内容区域。
- 平板实现：卡片宽 `364.5px`，两列自适应。
- 移动实现：卡片宽 `343px`，Copy 宽 `293px`，保持 `24px` 左右内边距。
- 短文本不显示展开入口；实际超过三行时才显示“展开全文”。

卡片宽度随视口和网格列数变化，不使用固定设计稿宽度；内边距、按钮高度、排版层级和交互状态与设计节点保持一致。

## 业务验证

- 局域网 HTTP 环境确认 `isSecureContext === false`。
- 页面任意位置粘贴文本或图片后自动识别并发送，无需主动读取剪贴板权限。
- 自动复制失败时选中完整文本并提示按 `Ctrl+C` 或长按复制。
- 文本卡片不重复渲染标题或副标题，按真实三行溢出决定是否显示全文展开。
- 图片、视频、文件上传均生成正确类型的 DataItem。
- 文件选择按钮成功触发浏览器原生 file chooser。
- 图片、视频预览区直接提供 Open，卡片操作区只保留 Save。
- 普通文件卡片保留 Open 和 Save。
- 所有异步用户操作由最外层错误边界统一提示。
- 桌面三列、平板两列、移动端单列响应式布局通过。
- 浅色及深色系统主题通过。
- 点击后 hover 状态立即清除，指针离开后恢复正常 hover 生命周期。
